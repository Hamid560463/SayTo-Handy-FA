# 🎙️ SayTo-Handy FA — دستیار تایپ صوتی آفلاین فارسی برای ویندوز
### مبتنی بر مدل سبک و آفلاین `vosk-model-small-fa-0.42` + معماری Handy و SayTo

[![Platform](https://img.shields.io/badge/Platform-Windows%2010%20%7C%2011-0078D6?style=flat-square&logo=windows)](https://github.com)
[![Engine](https://img.shields.io/badge/STT%20Engine-vosk--model--small--fa--0.42-16A34A?style=flat-square)](https://alphacephei.com/vosk/models)
[![Offline](https://img.shields.io/badge/Privacy-100%25%20Offline-0284C7?style=flat-square)]()
[![License](https://img.shields.io/badge/License-MIT-F59E0B?style=flat-square)]()

**SayTo-Handy FA** یک اپلیکیشن دسکتاپ ویندوزی، رایگان، متن‌باز و **۱۰۰٪ آفلاین** برای تبدیل گفتار به متن فارسی (Voice Typing / Dictation) است. این پروژه بهترین قابلیت‌های دو نرم‌افزار محبوب **[Handy](https://github.com/cjpais/Handy)** (تایپ مستقیم در هر پنجره فعال ویندوز با یک کلید میانبر سراسری) و **[SayTo](https://github.com/CycleSeeker/SayTo)** (تشخیص گفتار فارسی با موتور Vosk و اعمال هوشمند علائم نگارشی و نیم‌فاصله) را در یک پکیج یکپارچه و اجرایی (`.exe`) ترکیب کرده است.

---

## ✨ ویژگی‌های کلیدی

- 🔒 **۱۰۰٪ آفلاین و حفظ کامل حریم خصوصی:** تمام پردازش‌های صوتی روی پردازنده (CPU) کامپیوتر شما انجام می‌شود و هیچ صدای ضبط‌شده‌ای به اینترنت یا سرورهای ابری ارسال نمی‌گردد.
- ⚡ **فوق‌سبک و سریع با `vosk-model-small-fa-0.42`:** حجم مدل تنها **۴۷ مگابایت** است و بدون نیاز به کارت گرافیک (GPU) روی تمام لپ‌تاپ‌ها و کامپیوترهای معمولی با تأخیر کمتر از ۲۰ میلی‌ثانیه کار می‌کند.
- ⌨️ **تزریق مستقیم متن در تمام برنامه‌های ویندوز (معماری Handy):** کافی است در هر نرم‌افزاری (**Microsoft Word، Notepad، Telegram، WhatsApp، مرورگر کروم یا VS Code**) نشانگر ماوس را قرار دهید، کلید میانبر **`Ctrl + Shift + Space`** را بزنید و صحبت کنید تا متن فارسی مستقیماً در همان‌جا تایپ شود.
- ✍️ **موتور پس‌پردازش و نگارش هوشمند فارسی (معماری SayTo):**
  - **تبدیل فرمان‌های صوتی به علائم نگارشی:** پشتیبانی از گفتن عباراتی مانند *«ویرگول»* (`،`)، *«نقطه»* (`.`)، *«علامت سوال»* (`؟`)، *«علامت تعجب»* (`!`)، *«دونقطه»* (`:`) و *«نقطه سر خط»* (رفتن به خط جدید).
  - **اصلاح خودکار نیم‌فاصله‌ها (ZWNJ):** تبدیل خودکار *«می روم»* به *«می‌روم»*، *«کتاب ها»* به *«کتاب‌ها»* و *«بزرگ تر»* به *«بزرگ‌تر»*.
  - **یکسان‌سازی نویسه‌های فارسی:** تبدیل خودکار حروف عربی (`ي`، `ك`) به فارسی استاندارد (`ی`، `ک`) و ارقام فارسی.
- 📦 **دانلودر داخلی مدل با یک کلیک:** در نسخه اجرایی (`SayToHandy.exe`) نیازی به دانلود دستی مدل یا تنظیم مسیر فایل‌ها نیست؛ برنامه با یک کلیک مدل رسمی را دانلود و در مسیر استاندارد `%LOCALAPPDATA%\SayToHandy\models` نصب می‌کند.
- 📊 **پایگاه داده SQLite و خروجی اکسل (`.xlsx` / `.csv`):** ذخیره خودکار تاریخچه تایپ‌های صوتی به همراه سرویس بک‌اند **FastAPI** و داشبورد تحلیلی **Streamlit**.

## 🚀 روش اول: استفاده از نسخه نصبی و اجرایی ویندوز (`SayToHandy.exe`) — بدون نیاز به پایتون

اگر کاربر عادی هستید و نمی‌خواهید با کدهای پایتون درگیر شوید:

1. فایل اجرایی **`SayToHandy.exe`** (یا نصب‌کننده `SayToHandy_Persian_Setup.exe`) را از بخش **Releases** دانلود و اجرا کنید.
2. در اولین اجرا، روی دکمه **«📥 دانلود و نصب خودکار مدل فارسی (۴۷ مگابایت)»** کلیک کنید و منتظر بمانید تا نوار پیشرفت به ۱۰۰٪ برسد.
3. پس از نمایش پیام **«✅ آماده به کار!»**، پنجره برنامه را کوچک (Minimize) کنید.
4. در هر برنامه ویندوزی که هستید، کلید **`Ctrl + Shift + Space`** را فشار دهید، صحبت کنید و دوباره همان کلید را بزنید تا متن تایپ شود!

## 🛠️ روش دوم: ساخت فایل `.EXE` یا اجرا از روی سورس‌کد (ویژه توسعه‌دهندگان)

### ۱. کلون کردن مخزن و نصب پیش‌نیازها
ابتدا مطمئن شوید **Python 3.10+** روی ویندوز نصب است:

</div>

```bash
git clone https://github.com/YOUR_USERNAME/SayTo-Handy-FA.git
cd SayTo-Handy-FA
pip install -r requirements.txt
```

<div dir="rtl" align="right">

### ۲. اجرای مستقیم رابط گرافیکی دسکتاپ
</div>

```bash
python sayto_handy_gui_app.py
```

<div dir="rtl" align="right">

### ۳. کامپایل و تبدیل به فایل مستقل `SayToHandy.exe` (تک‌فایلی)
برای ساخت فایل `.exe` که تمام فایل‌های DLL موتور صوتی Vosk را در دل خود دارد، کافی است اسکریپت زیر را اجرا کنید:

</div>

```cmd
build_exe.bat
```

<div dir="rtl" align="right">

پس از اتمام کامپایل، فایل مستقل **`dist\SayToHandy.exe`** تولید می‌شود که روی هر کامپیوتر ویندوزی دیگری بدون نیاز به نصب پایتون قابل اجراست. همچنین برای ساخت ویزارد نصب استاندارد ویندوز (`Setup.exe`) می‌توانید فایل `installer_setup.iss` را در نرم‌افزار رایگان **Inno Setup** کامپایل کنید.

## 🗣️ جدول فرمان‌های صوتی نگارشی (SayTo Voice Commands)

هنگام صحبت کردن، با گفتن هر یک از عبارات زیر، علامت نگارشی معادل آن به صورت خودکار درج می‌شود:

| عبارت گفتاری هنگام دیکته | خروجی در متن | توضیح عملکرد |
| :--- | :---: | :--- |
| **«ویرگول»** | `، ` | درج ویرگول فارسی |
| **«نقطه»** | `. ` | پایان جمله |
| **«نقطه سر خط»** | `.\n` | بستن جمله و رفتن به خط جدید |
| **«سر خط»** یا **«خط جدید»** | `\n` | رفتن به خط بعدی (Enter) |
| **«پاراگراف جدید»** | `\n\n` | ایجاد پاراگراف تازه |
| **«علامت سوال»** | `؟ ` | درج علامت سؤال فارسی |
| **«علامت تعجب»** | `! ` | درج علامت تعجب |
| **«دو نقطه»** | `: ` | درج دو نقطه توضیحی |
| **«نقطه ویرگول»** | `؛ ` | درج نقطه‌ویرگول فارسی |
| **«گیومه باز» / «گیومه بسته»** | `«` / `»` | باز و بسته کردن گیومه فارسی |
| **«پرانتز باز» / «پرانتز بسته»** | `(` / `)` | باز و بسته کردن پرانتز |

## 📂 ساختار فایل‌های پروژه

</div>

```text
SayTo-Handy-FA/
├── sayto_handy_gui_app.py     # برنامه اصلی دسکتاپ ویندوز با رابط گرافیکی و دانلودر مدل (EXE Ready)
├── handy_sayto_agent.py       # نسخه سبک خط فرمان (CLI) برای اجرا در پس‌زمینه ویندوز
├── setup_model.py             # اسکریپت دانلود و استخراج خودکار مدل vosk-model-small-fa-0.42
├── backend_api.py             # وب‌سرویس FastAPI + پایگاه داده SQLite + خروجی Excel (Pandas/OpenPyXL)
├── streamlit_dashboard.py     # داشبورد تحلیلی و مدیریتی تحت وب با Streamlit
├── build_exe.bat              # کامپایلر یک‌کلیکی PyInstaller برای تولید dist/SayToHandy.exe
├── installer_setup.iss        # اسکریپت Inno Setup برای ساخت نصب‌کننده استاندارد ویندوز (Setup.exe)
├── run_windows.bat            # لانچر خودکار ساخت venv، نصب پکیج‌ها، دانلود مدل و اجرای برنامه
├── requirements.txt           # فهرست پکیج‌های پایتون مورد نیاز
└── README.md                  # مستندات کامل پروژه در گیت‌هاب
```

## 🌐 اجرای سرویس FastAPI و داشبورد Streamlit (اختیاری)

برای دسترسی به REST API، آپلود فایل‌های صوتی WAV و دریافت گزارش‌های مدیریتی Excel:

</div>

```bash
# اجرای وب‌سرویس FastAPI روی پورت 8000
uvicorn backend_api:app --host 127.0.0.1 --port 8000 --reload

# اجرای داشبورد گرافیکی Streamlit
streamlit run streamlit_dashboard.py
```
